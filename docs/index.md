## 읽기 모드와 접근성

- **집중해서 읽기:** 브라우저의 읽기 모드·확대 기능을 사용할 수 있습니다. 이 사이트는 텍스트, 표, 코드와 각주를 보존하므로 슬라이드나 PDF 대신 텍스트 교재를 사용해도 됩니다.
- **키보드로 이동하기:** 페이지를 연 뒤 `Tab` 키를 누르면 본문으로 건너뛰는 링크가 나타납니다. `Tab`과 `Shift`+`Tab`, `Enter`로 목차·링크·검색을 이용할 수 있으며, 현재 초점은 뚜렷하게 표시됩니다.
- **화면 확대와 작은 화면:** 브라우저 확대, 운영체제의 글자 크기, 가로 320px 화면에서도 내용을 다시 흐르게 표시합니다. 넓은 표와 코드는 가로로 스크롤할 수 있습니다.
- **움직임과 인쇄:** 운영체제에서 동작 감소를 설정하면 불필요한 전환을 줄입니다. 인쇄 또는 PDF 저장 시에는 본문과 출처를 중심으로 출력합니다.

정책과 인공지능 관련 내용은 확인 시점의 공식 자료를 기준으로 서술했습니다. 제도 명칭, 적용 범위, 제품 기능처럼 변동 가능성이 큰 내용은 최신 교육부·국제기구 자료로 다시 확인해야 합니다.
