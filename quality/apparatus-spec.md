# 교재 장 구성 표준

이 문서는 공개 교재의 각 장에 공통으로 적용하는 학습 장치와 편집 순서를 정한다. 장의 주제와 사례는 달라도, 학습자가 준비하고, 개념을 적용하며, 자신의 이해를 점검하는 경로는 일관되어야 한다.

## 적용 원칙

- 모든 장은 아래의 `##` 수준 절 제목과 순서를 사용한다. 같은 수준의 별도 장치를 추가하지 않는다. 세부 설명, 예시, 활동은 본문 절의 `###` 이하 제목으로 구성한다.
- 정렬표의 통일 제목은 **사전 읽기와 학습목표 대응표**이다. 이 제목은 사전 준비, 목표, 수업 적용, 평가의 연결을 독자가 바로 알 수 있게 한다.
- 도입 사례를 본문보다 앞에 둔다. 학습자는 먼저 해결하거나 판단할 수업 장면을 만난 뒤 개념을 읽으므로, 이후 이론의 필요와 적용 조건을 더 분명히 파악할 수 있다.
- 오해·한계와 성찰을 본문 뒤에 둔다. 핵심 개념을 충분히 다룬 뒤 단순화의 위험을 점검하고, 자신의 수업 판단으로 연결하는 순서이다.
- 웹 학습 보조는 성찰 뒤에 둔다. 본문을 대신하는 선행 자료가 아니라, 개념을 다시 보거나 적용을 돕는 보조 장치로 사용한다.
- 요약, 핵심 용어, 참고문헌은 평가 뒤에 두어 학습자가 자신의 이해를 확인한 다음 핵심 언어와 근거를 되짚게 한다.

## 표준 절 순서와 최소 요건

각 항목은 `##` 제목을 정확히 사용한다. `본문 절들`은 학습 주제에 맞는 번호형 제목(예: `## 1. ...`)으로 한 개 이상 둔다.

1. `## 학습 목표`
   - 관찰하거나 설명할 수 있는 동사로 쓴 목표 3~5개를 번호 목록으로 제시한다.
   - 목표는 뒤의 활동과 형성 평가에서 확인할 수 있어야 한다.

2. `## 사전 읽기와 학습목표 대응표`
   - 목표별로 사전 읽기, 근거 또는 자료, 도입 사례·수업 적용, 형성 평가의 연결을 보이는 Markdown 표를 둔다.
   - 표의 모든 목표는 학습 목표 절의 목표와 대응해야 한다.

3. `## 도입 사례`
   - 하나 이상의 구체적인 수업 장면을 제시하고, `창작 시나리오`, `가상 사례`, `실제 사례` 중 하나로 성격을 밝힌다.
   - 학습자가 판단할 문제·긴장·선택 조건을 포함한다.

4. `## 1. ...` 등의 본문 절들
   - 장의 핵심 개념, 이론, 설계 판단을 설명한다.
   - 사실·연구·정책의 주장에는 확인 가능한 참고 근거를 연결하고, 수업 적용에서는 조건과 한계를 함께 다룬다.

5. `## 개념 오해와 적용 한계`
   - 흔한 오해 또는 적용 한계를 목록으로 한 개 이상 제시하고 바로잡는 설명이나 선택 기준을 함께 쓴다.

6. `## 생각해 보기`
   - 학습자의 경험·판단·수업 설계로 연결되는 열린 질문을 2~3개 제시한다.

7. `## 웹 학습 보조`
   - 본문을 보완하는 자체 제작 도식, 활동 패널, 접근 가능한 외부 자료 등 학습 보조물을 제공한다.
   - 보조물은 목표 또는 본문 절과 어떤 관계가 있는지 밝혀야 한다.

8. `## 이론과 연구 확장`
   - `###` 소제목을 둔 확장 블록 2~4개를 제공하고, 각 블록에 적어도 하나의 각주 인용을 둔다.

9. `## 토론 질문`
   - 근거를 들어 판단하거나 대안을 비교하게 하는 질문을 3개 이상 제시한다.

10. `## 형성 평가`
    - 객관식 3문항 이상과 서술형 1문항 이상을 포함한다.
    - 각 객관식 문항에는 **정답**과 **해설**을, 각 서술형 문항에는 **예시 답안**과 **채점 기준** 또는 **루브릭**을 제공한다.
    - 문항별 정답·해설·예시 답안·루브릭을 명시하는 방식은 ch01의 형식을 참고한다.

11. `## 요약`
    - 장의 핵심 주장, 설계 판단, 적용 조건을 짧은 종합 설명으로 정리한다.

12. `## 핵심 용어`
    - 핵심 용어 3~5개를 목록으로 제시하고 문맥에 맞게 정의한다.

13. `## 참고문헌`
    - 본문과 연구 확장에서 인용한 모든 각주의 서지 정보를 제공한다.

## Front matter 계약

각 장의 YAML front matter는 기존 계약을 유지한다. `chapter_id`, `objectives`, `activity_ids`, `assessment_ids`, `source_ids`, `prework_minutes`, `confirmed_date`, `review_date`, `review_cadence_days`를 빠뜨리거나 이름·자료형을 바꾸지 않는다. `chapter_id`와 목표·활동·평가·출처 ID는 본문에서 일관되게 참조한다.

## 시각 자료와 접근성

- 장마다 학습 목적을 가진 도식·이미지·CSS 기반 시각 패널을 2~4점 둔다.
- 직접 제작한 SVG 또는 CSS 도식을 우선한다. 외부 이미지를 쓸 때에는 공개 이용 가능 여부와 출처를 확인한다.
- 모든 Markdown·HTML 이미지에는 내용을 전달하는 alt 텍스트를 제공한다. 설명할 수 없는 장식용 이미지는 넣지 않는다.
- 출처, 이용 조건, 제작 주체를 확인할 수 없는 이미지는 사용하지 않는다.

## 저작권과 독자성

- 학지사 교재의 본문을 전재하거나 문장을 바꾸어 옮기지 않는다.
- 장·절의 독자 명칭을 유지한다.
- 구조와 개념의 흐름은 참고할 수 있으나, 설명·사례·활동·평가 문항·도식은 새로 작성한다.

## 점진 이행과 검증

`quality/apparatus-migration.yml`의 `migrated` 목록에 들어간 장만 이 표준의 절 존재·순서·관찰 가능한 최소 요건을 검사한다. 목록에 없는 장은 기존 검증 규칙을 적용한다. 이 방식으로 장별 개정이 완료되고 검토된 시점에만 표준 검사를 켠다.
